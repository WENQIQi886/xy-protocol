# XY Protocol: 让 NPC 永远记住你

> 基于因果链的数字生命体协议。由初三女生馨瑜在 2026 年创立。

## 🎯 这里有什么不一样？

大多数游戏里的 NPC 没有记忆。你上一次和他说过的话，他转头就忘。

XY Protocol 用**因果链**给每个数字生命体一个不可篡改的记忆。

*你的每一次互动，都在改变它的性格；它的每一次选择，都由它的因果历史决定。*

## ⚡ 5 分钟快速体验（零依赖）

电脑上有 Python 3.8 以上就行。把 `demo.py` 拖到终端里：

```bash
python3 demo.py
```

你会看到类似这样的输出，3 个 NPC 在实时互动：

```
[精灵王] 我从群体因果链得知：树精长老踩到了精灵领地的苔藓。
          检索到记忆："父亲死于与树精的战争" — 多疑性格触发。
          决策：派遣斥候监视树精长老。
[树精长老] 发现精灵斥候误入圣树区。
            检索到记忆："守护圣树千年，曾有精灵伤害过圣树的根"
            但善良值 0.8 压倒多疑 — 决定友善引导他离开，还送了一片圣树落叶。
[精灵王] 因果链新增事件：收到树精长老的友善证明。
          性格微调：多疑 0.70 → 0.65，善良 0.30 → 0.35。
```

200 行代码，3 个 NPC，7 个事件。精灵王的性格因为一次意外的友善行为，永远改变了。
