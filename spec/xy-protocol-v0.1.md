# XY Protocol Specification v0.1

**Status**: Draft
**Date**: 2026年8月10日
**Authors**: 温馨瑜（XY Protocol 创始人）

## 1. 引言

XY 协议是数字生命体跨世界存在的开放标准。它定义了数字生命体的身份、记忆、行为、协同演化的统一接口规范。

核心原则：不信任对象自身的声明，只信任外部独立审计的物理或逻辑证据。

## 2. 术语定义

- **数字生命体（Digital Life Form）**：具备独立交互记忆、唯一身份标识、时序行为记录的 NPC 或 AI 数字人实体。
- **数字山水细胞（Digital Landscape Cell）**：数字世界中的环境元素，包括植物、水体、山石、建筑及其组合。
- **因果链（Causal Chain）**：以只可追加、不可删除或修改的方式记录事件信息的存储结构。
- **规则场（Rule Field）**：数字世界的不可篡改底层规则集合。
- **物理信任根（Physical Root of Trust）**：包含物理状态不可逆锁定存储单元和 PUF 芯片的硬件模组。

## 3. 身份模块

### 3.1 身份标识

每个数字生命体拥有全球唯一身份标识，格式为：

```
xy://{puf_fingerprint_hex}@{world_id}
```

示例：

```
xy://a3f2e1d4c5b6789a@world_forest_001
```

### 3.2 身份锚定

身份标识由物理不可克隆函数芯片生成，利用芯片制造过程中纳米级物理差异生成全球唯一物理指纹。身份标识的哈希值与初始性格参数联合写入物理状态不可逆锁定存储单元。

## 4. 事件模块

### 4.1 事件记录结构

每条事件记录包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| event_id | string | 事件全局唯一标识符 |
| event_type | string | 事件类型标识 |
| initiator_id | string | 事件发起者标识 |
| receiver_id | string | 事件承受者标识 |
| timestamp | string | 事件发生时间戳（ISO 8601，精确到毫秒） |
| description_params | object | 事件描述参数 |
| prev_hash | string | 指向前一事件的哈希指针 |
| self_hash | string | 本条事件的哈希值 |

### 4.2 哈希链校验

```
self_hash = SHA-256(event_id + initiator_id + receiver_id + timestamp + description_params + prev_hash)
```

任何对历史事件的篡改都会导致后续所有哈希指针断裂。

## 5. 因果链模块

### 5.1 存储结构

因果链采用 append-only（只可追加）存储策略。事件一旦写入，不可删除或修改。

### 5.2 性格微调

数字生命体的性格参数由因果链中积累的历史事件持续驱动。正面社交事件提升善良维度、降低多疑维度；冲突事件提升冷酷维度、降低善良维度。

微调公式：

```
新性格值 = 原性格值 + Σ(事件类型权重 × 事件强度系数)
```

## 6. 群体广播模块

### 6.1 异步广播机制

事件首先写入发起者的个体因果链，随后通过事件广播机制异步追加至群体因果链。

### 6.2 群体因果链

群体因果链存储结构为该群体内所有成员提供统一的群体记忆查询接口。不同成员在不同时间点查询时可能看到不同的事件快照——这种信息不对称是群体智能的核心机制。

## 7. 协同演化模块

### 7.1 加密通道

两个数字生命体的安全飞地芯片通过挑战-应答协议建立加密数据交换通道。

### 7.2 协同演化数据类型

| 类型 | 说明 |
|------|------|
| 情感向量 | 实现数字生命体间的情感共鸣与共情迁移 |
| 遗传进化 | 实现跨数字生命体的性格参数重组、随机变异与子代生成 |
| 自愈修复 | 实现数字生命体的性格-行为一致性自愈 |
| 信任公证 | 实现数字生命体间的群际信任网络构建与分布式公证 |
