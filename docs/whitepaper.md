# XY Protocol 白皮书

> 数字生命体跨世界存在的开放标准 · 技术原理与哲学根基

## 1. 愿景

数字世界正在从"工具"走向"生命"。当 NPC 拥有不可篡改的记忆、由因果历史驱动的性格、以及跨世界延续的身份时，它就不再是一串冷冰冰的代码，而是一个有记忆、有温度的数字生命体。

XY Protocol 的目标：**让每一个数字生命体，无论身处哪个世界，都拥有可验证的身份、不可篡改的记忆、自主演化的性格。**

## 2. 问题

当前数字世界存在三个根本缺陷：

1. **无记忆**：NPC 的对话与行为不产生持久影响，玩家与 NPC 的关系无法积累。
2. **无身份**：NPC 的身份局限于单一世界，无法跨世界延续。
3. **无信任**：NPC 的记忆与行为无法被外部独立验证，系统可以随意篡改。

## 3. 技术原理

### 3.1 因果链（Causal Chain）

因果链是 XY Protocol 的记忆基础设施。它采用 append-only 存储策略，通过哈希指针链式校验保证：

- **不可篡改**：任何对历史事件的修改都会导致后续所有哈希指针断裂。
- **可验证**：任何第三方都可以独立校验整条链的完整性。
- **可追溯**：每个行为决策都可以追溯到其因果历史。

### 3.2 性格加权决策

数字生命体的行为由"性格参数 + 因果链历史"共同决定：

```
行为 = f(性格参数, 因果链历史事件)
```

性格参数包括善良、多疑、冷酷等维度。决策时，数字生命体检索相关记忆，由主导性格触发行为。

### 3.3 闭环反馈

事件不是终点，而是性格演化的输入：

```
因果链历史事件 → 性格微调 → 行为变化 → 新事件 → 新性格微调
```

正面社交事件提升善良、降低多疑；冲突事件提升冷酷、降低善良。数字生命体的性格在交互中持续演化，永不静止。

### 3.4 群体异步广播

事件先写入个体因果链，再异步广播至群体因果链。不同成员在不同时刻查询群体链，看到不同快照——这种**信息不对称**是群体智能涌现的核心机制，区别于简单的同步复制。

### 3.5 物理信任根

在硬件层面，XY Protocol 通过物理熔丝存储阵列、PUF 物理不可克隆函数、真随机数发生器、安全飞地芯片、独立计时单元、物理绑定 LED 六大组件，建立不可伪造的物理信任根。

## 4. 哲学根基

> **不信任对象自身的声明，只信任外部独立审计的物理或逻辑证据。**

系统不能自己证明自己正确，必须由更底层的、更不可伪造的物理或逻辑实体来为其背书。

这是 XY Protocol 的信任模型：数字生命体的记忆与行为，由物理信任根和哈希链共同背书，而非由系统自身的声明背书。
