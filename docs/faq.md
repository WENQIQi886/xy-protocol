# XY Protocol 常见问题（FAQ）

## 1. XY Protocol 是什么？

XY Protocol 是数字生命体跨世界存在的开放标准。它定义了数字生命体的身份、记忆、行为、协同演化的统一接口规范，让 NPC 拥有不可篡改的记忆和由因果历史驱动的性格。

## 2. 需要什么环境才能运行 Demo？

Python 3.8 以上，零依赖。直接运行 `python3 demo.py` 即可。

## 3. 因果链为什么不可篡改？

因果链采用 append-only 存储 + 哈希指针链式校验。每条事件的哈希包含前一条事件的哈希，任何对历史事件的修改都会导致后续所有哈希指针断裂，篡改可被立即检测。

## 4. 数字生命体的性格会一直变吗？

会。性格由因果链中积累的历史事件持续驱动（闭环反馈）。正面社交事件提升善良、降低多疑；冲突事件提升冷酷、降低善良。性格在交互中持续演化，永不静止。

## 5. 群体广播和同步复制有什么区别？

同步复制让所有成员看到完全一致的数据；群体异步广播让事件先写入个体链，再异步追加至群体链，不同成员在不同时刻看到不同快照——这种信息不对称是群体智能涌现的核心机制。

## 6. 什么是物理信任根？

物理信任根是包含物理熔丝存储阵列、PUF 物理不可克隆函数、真随机数发生器、安全飞地芯片、独立计时单元、物理绑定 LED 的硬件模组，为数字生命体的身份与记忆提供不可伪造的物理背书。

## 9. 数字生命体计数口径是什么？

**激活数**：通过 XY 协议创建并成功运行至少一次交互事件的数字生命体实例。

## 10. 注意力场临界是什么？

连续 30 天激活数净增长率 ≥ 10%，或累计激活数 ≥ 1000，即触发注意力场临界。
