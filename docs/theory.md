# 底层原理（Theory）

本页记录参数化成像方法的核心原理，重点为两项独立贡献：领域通用公式修正、短基线远距失效定量模型。

## 1. 线性化测距公式及其局限

经典线性化测距公式在近距离场景近似可用，但在远距离场景（约 50m 以上）存在系统性低估。实验测量表明，该场景下误差被低估约 2.5 倍。

> 待补充：完整推导过程与原始公式，将依据专利说明书与实审答辩材料（`validation_package_v3.0`）同步至此。

## 2. 短基线远距失效定量模型

短基线配置在远距离场景下因基线占比下降导致失效。本工作给出该失效机制的定量描述，作为参数化成像的适用范围界定依据。

## 3. 纯角度法解耦

在无需额外测距信息的约束下，仅依靠多摄像头同步拍摄获得的角度信息完成解耦。A3 实验对比结果见 [experiments.md](experiments.md)。
